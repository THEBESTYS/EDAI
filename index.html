STEP 1: ED School 홈페이지 접속

English Discoveries 학습 플랫폼에 접속하여 계정을 생성하세요.

ED School이란?

English Discoveries는 세계적인 영어 학습 플랫폼으로, 개인의 수준에 맞춘 체계적인 영어 학습을 제공합니다.

  • AI 기반 맞춤형 학습 경로
  • 말하기, 듣기, 읽기, 쓰기 종합 훈련
  • 실시간 발음 평가 및 피드백
  • 글로벌 인증시험 대비 콘텐츠
ED School 홈페이지 바로가기

STEP 2: 스피킹 맥스에서 AI와 대화 녹음

ED School의 "스피킹 맥스" 모듈에서 AI와 대화하고 녹음 파일을 준비하세요.

스피킹 맥스 접속 방법

  1. ED School 로그인 후 "스피킹 맥스" 메뉴 선택
  2. AI 튜터와의 대화 주제 선택 (일상대화, 비즈니스, 여행 등)
  3. 마이크 테스트 후 대화 시작
  4. AI의 질문에 자연스럽게 답변

녹음 팁

  • 조용한 환경에서 녹음하세요
  • 자연스러운 발음과 속도로 말하세요
  • 최소 2-3분 이상 대화를 진행하세요
  • 녹음 파일은 MP3, WAV, M4A 형식으로 저장

샘플 녹음 듣기

* 위 샘플은 영어 대화 녹음의 예시입니다.

STEP 3: 녹음 파일 업로드

스피킹 맥스에서 녹음한 파일을 업로드해주세요.

파일을 여기로 끌어오거나 클릭하세요

MP3, WAV, M4A 형식, 최대 50MB

업로드 요구사항

  • 파일 크기: 50MB 이하
  • 지원 형식: MP3, WAV, M4A
  • 권장 길이: 2-5분
  • 권장 내용: 영어 대화 녹음

업로드된 음성 파일은 레벨 분석 목적으로만 사용되며, 분석 완료 후 24시간 내에 삭제됩니다.

진단 결과에 대한 중요 안내

1. 본 스피킹 테스트는 간이 진단(Level Indicator)입니다. 정확한 ED 레벨과 학습 코스는 종합적인 배치고사(Placement Test) 후에 결정됩니다.

2. 표시된 CEFR, TOEIC, IELTS 점수는 참고용 추정치이며, 실제 공인시험 점수를 보장하지 않습니다.

3. ED 학습의 궁극적 목표는 체계적인 과정을 통해 실제 영어 의사소통 능력을 향상시키는 것입니다.
